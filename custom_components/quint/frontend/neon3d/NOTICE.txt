Quint v1.43.0 patched neonplan3d-3d.js so floors, walls and furniture can take colours from
globalThis.__qcol (set by the Quint panel). Without it the file draws exactly as before.

Quint v1.48.0 also patched the themed material shader (function Qe) so, when globalThis.__qcol.real is set,
the light look draws terracotta roof tiles, wood-plank and tile floors, soft wall shading and fine outlines.
Without it the file draws as before.

Quint v1.49.0 changed neonplan3d.js (the "Extensions" tab and the shop gift pop-up were removed) and
neonplan3d-editor.js (the page behind "Import" now only imports furniture packs, modules and 3D models; the
teaser under the furniture library points to it). quint-models.js is new Quint code (converts GLB/GLTF/OBJ/STL
files into furniture parts in the browser). neon3d/builtin/quint.furniture.json is a furniture pack made by
Quint and signed with Quint's own key (see PACK_PUBLIC_KEYS in packs.py); packs.py also accepts unsigned
furniture of the user's own ("own.*" ids: furniture only, no Pro features, no code).

Quint v1.50.0 patched neonplan3d-3d.js further: (1) the reach and fall-off of a lamp's light on floors and walls
(functions W2 and F0, helper qcPw) shrink to a pool around the lamp when globalThis.__qcol.pool is set; (2) the
wall shader (function ai) cuts the walls that face the camera low, with solid caps, instead of drawing them as glass
when globalThis.__qcol.cut is set. Without these flags the file draws as before.

Quint v1.53.0 added a "world" to neonplan3d-3d.js (functions qcWFrame, qcWBuild, qcWStep, qcWTint, qcWFit, qcWDrop,
hooked into placeGround, fit, render and dispose): when globalThis.__qcol.world is set, the house stands on a plot
of land with a road in front, a driveway to the main door (found from the plan's exterior doors), a front garden
(fence, hedge, flower beds, trees, lamps, mailbox, bench), cars on the road, clouds with shadows, lamps that light at
night and fireflies. It changes its colours with globalThis.__qcol.sky (the sun's height, set by Quint). Without
the flag the file draws as before. quint-sky.js is new Quint code (the animated sky behind the house).
